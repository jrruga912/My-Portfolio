Database Project

Clinic Database

Clinic DBO is a comprehensive database management system designed to streamline healthcare administration. It provides a centralized platform for handling patient appointments, medical records, and personnel management with a focus on data accuracy and workflow efficiency.

The system features a robust administrative dashboard that allows for the seamless addition of patients and staff, as well as real-time appointment scheduling. By maintaining a detailed history of the database, the platform ensures that all medical and administrative interactions are logged, providing a secure and traceable record for clinic operations.

Login System

Integrated login system that identifies user roles upon authentication. Staff gain access to patient scheduling, while Admins unlock the dashboard for adding personnel and auditing database history.

Patient Management

Enables Doctors and Nurses to register and view patients with fields for Name, Gender, Contact, and History. Includes automated Patient ID generation upon creation for seamless tracking and an organized directory for quick record management.

Appointment Management

Allows Doctors and Nurses to schedule appointments on a patient's preferred date. The system provides the flexibility to select specific attending doctors, ensuring organized scheduling and efficient patient-to-provider matching.

Staff Management

A dynamic system for managing clinic staff, including roles, responsibilities, and scheduling.

History Tracking

Maintains a comprehensive audit trail of all system activities. This module tracks the database history, allowing staff and admins to review past appointments, record updates, and clinical logs to ensure accountability and data transparency.
